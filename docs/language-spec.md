# Tsumugi 言語仕様

バージョン: 0.1

## コメント

`#` から行末まで。

```
# これはコメント
let x = 10  # ここもコメント
```

## データ型

| 型 | リテラル例 |
|---|---|
| 整数 | `0`, `42`, `-3` |
| 浮動小数点 | `3.14`, `0.5` |
| 文字列 | `"hello"`, `"line\n"` |
| 真偽値 | `true`, `false` |
| null | `null` |

### 文字列エスケープ

| エスケープ | 意味 |
|---|---|
| `\n` | 改行 |
| `\t` | タブ |
| `\\` | バックスラッシュ |
| `\"` | ダブルクォート |

## 変数

```
let x = 10
let name = "tsumugi"
let flag = true
```

再代入は同スコープ内で `let` を再度使う。

## 演算子

### 算術

| 演算子 | 意味 |
|---|---|
| `+` | 加算 / 文字列結合 |
| `-` | 減算 / 単項マイナス |
| `*` | 乗算 |
| `/` | 除算（整数同士は整数除算） |

### 比較

| 演算子 | 意味 |
|---|---|
| `==` | 等しい |
| `!=` | 等しくない |
| `<` | 小さい |
| `>` | 大きい |
| `<=` | 以下 |
| `>=` | 以上 |

### 論理

| 演算子 | 意味 |
|---|---|
| `and` | 論理積 |
| `or` | 論理和 |
| `not` | 論理否定 |

### 優先順位（低→高）

1. `or`
2. `and`
3. `==` `!=` `<` `>` `<=` `>=`
4. `+` `-`
5. `*` `/`
6. `not` `-`（単項）
7. 関数呼び出し

## 条件分岐

```
if 条件
    本体
end

if 条件
    本体
else
    本体
end
```

## ループ

```
while 条件
    本体
end
```

## 関数

```
fn 関数名(引数1, 引数2)
    return 式
end
```

呼び出し:

```
let result = add(3, 4)
```

## 組み込み関数

| 関数 | 説明 |
|---|---|
| `print(値)` | 値を標準出力に表示。複数引数はスペース区切りで出力 |

## 真偽判定

以下は偽（falsy）として扱われる:
- `false`
- `null`
- `0`（整数のゼロ）
- `0.0`（浮動小数点のゼロ）
- `""`（空文字列）

それ以外はすべて真（truthy）。

## エラーメッセージ

パースエラー・ランタイムエラーともに行番号が付与される。

```
2行目: let の後に識別子が必要です。got: Assign
3行目: 未定義の変数: z
1行目: ゼロ除算
3行目: 型エラー: Str("hello") Add Int(1) は計算できません
```
